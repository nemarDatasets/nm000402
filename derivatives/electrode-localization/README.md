# Electrode localization (author-provided)

Per-subject `electrodes.tsv`/`electrodes.json` exactly as released by the data authors under `files/DATA/sub-*/derivatives/` of Pennsieve dataset 530 v3 (doi:10.26275/dely-fzwx). Columns: `label`, `x`/`y`/`z` (voxel space, per the authors' `electrodes.json`), `matter` (tissue class), `brain_area` (Desikan-Killiany ROI). The images defining the voxel space are not part of the release.
